# AI 통역 큐브 제품 홍보 사이트
빌드 도구 없이 실행하는 정적 사이트입니다. 한국어 반응형 페이지, 실제 시연영상, 컨셉 이미지, 동작 줄이기 설정 대응, 문의 파일 저장을 제공합니다.

로컬 미리보기: `python3 -m http.server 8765`

GitHub 배포: 이 폴더를 독립 저장소의 main 브랜치에 올린 뒤 Settings → Pages → Source에서 GitHub Actions를 선택합니다. 포함된 워크플로가 배포합니다. 영상/이미지 공개 가능 여부를 확인하고 공개하세요.

문의 이메일 주소 미확정으로 실제 전송 기능은 연결되지 않았습니다. 폼은 문의 내용을 로컬 파일로 저장하며 서버로 보내지 않습니다. 언어 화면과 파형은 이해를 위한 UI 예시로 실제 입력과 연결되지 않습니다. 컨셉 이미지는 최종 제품 사진이 아닙니다.
